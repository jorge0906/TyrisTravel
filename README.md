# 🌍 TyrisTravel

![Licencia](https://img.shields.io/badge/licencia-MIT-blue.svg)

**TyrisTravel** es una aplicación orientada a la gestión y reserva de experiencias turísticas y viajes, pensada para ofrecer una navegación ágil e intuitiva a los usuarios.

---

## 🚀 Características

* **Gestión de viajes y experiencias:** Consulta de destinos disponibles con información detallada.
* **Sistema de reservas:** Flujo sencillo para la selección y reserva de paquetes turísticos.
* **Panel de usuario:** Interfaz centralizada para gestionar datos de usuario y reservas activas.
* **Diseño adaptativo:** Interfaz optimizada para su correcto funcionamiento en diferentes dispositivos.

---

## 🛠️ Tecnologías utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend / Control de versiones:** Git & GitHub
